# Agent prompt — Subscription Line Watch (created as a draft, never run in the demo)

```
Create an agent called "Subscription Line Watch" on the Harborline Private Capital domain. On the first Monday after each quarterly data refresh (next run after 2026-12-29 at 7am), look at the latest quarter end in V_FUND_PERFORMANCE_LATEST. For every fund with USES_SUBSCRIPTION_LINE true, calculate CREDIT_LINE_PCT_OF_NAV and list the funds above 15 percent with their manager, strategy, vintage year, NAV, line balance and line limit. Then using V_SUBSCRIPTION_LINE_IRR_GAP, for vintages less than four years old at that quarter end, find every vintage and strategy where IRR_GAP_PTS (funds with a line minus funds without at the same fund age) is above 3 points and FUNDS_WITH_LINE and FUNDS_WITHOUT_LINE are both at least 3. If anything triggers, investigate which funds drive it, whether their line balance rose quarter on quarter, and whether their quarterly return changed, and send Index Research a summary with the finding, the affected funds and cohorts, and the supporting data. Never repeat the same alert in consecutive quarters for the same fund and send nothing if nothing triggers.
```
